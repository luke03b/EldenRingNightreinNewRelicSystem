⚔️ The True Relic System

🏠 Benvenuto nel True Relic System

The True Relic System è un'applicazione web per gestire il sistema di crafting delle reliquie di Elden Ring Nightreign. Pensata per 3 giocatori, permette di creare, fondere e gestire reliquie secondo un regolamento personalizzato.

Funzionalità: Inventario reliquie con filtri • Fusione con wizard a 5 step • Sorteggio colore ed effetti • Test degradazione • Token cromatici e di creazione • Registro fusioni • Esportazione/importazione JSON
